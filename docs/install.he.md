# התקנה

## עם HACS

1. פותחים את **HACS**, מחפשים **Easy Sidebar Pro** ובוחרים **Download**.
2. מפעילים מחדש את Home Assistant.
3. עוברים אל **הגדרות ← מכשירים ושירותים ← הוספת אינטגרציה ← Easy Sidebar Pro**.
4. מרעננים את הדפדפן, וסוגרים ופותחים מחדש את האפליקציה הרשמית. העיפרון מופיע ליד כותרת סרגל הצד.

אין צורך לשנות את `configuration.yaml`.

!!! tip "לא נמצאת בחיפוש של HACS?"
    מוסיפים אותה כמאגר מותאם אישית: ב-HACS פותחים את התפריט (שלוש נקודות), בוחרים **Custom repositories**, מזינים `https://github.com/bareli/easy_sidebar_pro`, בוחרים בקטגוריה **Integration** וממשיכים משלב 1.

## התקנה ידנית

מעתיקים את התיקייה `custom_components/easy_sidebar_pro` מתוך [המאגר](https://github.com/bareli/easy_sidebar_pro) אל `<config>/custom_components/`, מפעילים מחדש את Home Assistant וממשיכים משלב 3 למעלה.

## מגיעים מ-Sidebar Organizer

מסירים קודם את Sidebar Organizer; הפעלה של שניהם יחד אינה נתמכת. קבוצות, קבוצות שמתחילות מקופלות, קבוצה אחת פתוחה בכל פעם, כפתור קיפול הכול, עיצוב הקו המפריד ופריטי רשת בתחתית יש להם מקבילות כאן. צבעי הרקע והגלילה של הסרגל נשארים בידי ערכת הנושא של Home Assistant. קבוצות בתחתית, קישורים מותאמים עם תבניות וקובץ הגדרות YAML אינם נתמכים.

## הסרה

מוחקים את האינטגרציה ומרעננים את הדפדפן. הסדר והלוחות המוסתרים של Home Assistant עצמה נשארים כפי ששמרתם אותם בפעם האחרונה.
