## Summary

In the dark theme the error colour in the options block (`rgb(221,107,98)`) on the options panel (`rgb(40,40,40)`) is **4.46:1**. It colours the 12 px error messages (link address, entity id) and the 14 px "Delete link" button text. The light theme passes (5.06:1).

## Steps to reproduce

1. 8173, dark theme (`frontend/set_user_data` key `theme` = `{dark:true}`), editor, Add link, type `ftp://x` in the address, Enter.
2. Measure the error text and `.btn.remove` colour against the options panel background.

## Expected

4.5:1 for normal text.

## Actual

4.46:1 (error text and Delete link text). The button border is also 4.46:1 (needs only 3:1).

## Evidence

`~/.claude/qa-playwright/espjs/a11y-10.mjs` (DARK=1): `error cr 4.46, remove cr 4.46`; light 5.06.

## Screenshots

![error and delete in dark](https://github.com/bareli/easy_sidebar_pro/blob/main/qa/evidence/BUG-019-options-error-dark.png?raw=1)

## Likely root cause

Likely: `--esp-error-color` is derived against the sidebar background (28,28,28) but the options panel is the lighter `--secondary-background-color` (40,40,40).

## Relevant files

- `custom_components/easy_sidebar_pro/www/easy-sidebar-pro.js` (`--esp-error-color`, `.btn.remove`, `.row-opts .error`)

## Recommended remediation

Derive the error colour against the lightest background it is drawn on, or lift it a few percent in dark.
