## Summary

The editor cleans group names with `cleanName`, which strips only C0 controls and DEL. The server rejects
every Unicode `Cc` character, including C1 (U+0080-U+009F). A name pasted with an invisible C1 character
(U+0085 is common in text that went through a Windows-1252 / Latin-1 round trip) looks normal in the
field, is accepted by the editor, and then Done fails with
`השמירה נכשלה: groups['qyfqa9o9']: name contains control characters`: English, with an internal group id,
about a character the user cannot see or find.

## Steps to reproduce

1. qa_admin, open the editor.
2. Paste `סלון<U+0085>מטבח` into a group name (the field shows `סלוןמטבח`), press Enter.
3. Click Done.

## Expected

The editor and server agree on what a valid name is (PROJECT.md *Fix constraints*: "Server-side validation
is authoritative; the editor validates too"): either the editor removes C1 characters like it removes C0,
or it rejects the name inline before saving.

## Actual

No inline error; Done fails with the server message above; the editor stays open (nothing lost).
Reproduced twice. A trailing U+0085 does not fail, because Python's `str.strip()` treats U+0085 as
whitespace; only an embedded one does.

## Evidence

```
#6 input shows "סלוןמטבח"   error before Done: null
#6 after Done editing true  error: השמירה נכשלה: groups['qyfqa9o9']: name contains control characters
```

Failing test: `tests_js/qa-regressions.test.js` ("BUG-014: cleanName removes C1 control characters the
server rejects"): actual `'סלון\x85מטבח'`, expected `'סלוןמטבח'`.

## Screenshots

## Likely root cause

`www/layout.js` `cleanName` uses `/[\u0000-\u001f\u007f]/g`; `layout.py` `_name` rejects any
`unicodedata.category(c) == "Cc"` (which includes U+0080-U+009F).

## Relevant files

- `custom_components/easy_sidebar_pro/www/layout.js` (`cleanName`)
- `custom_components/easy_sidebar_pro/layout.py` (`_name`)

## Recommended remediation

Extend the `cleanName` character class to `\u0080-\u009f`. The error-text part is covered by UX-007.

## Fix prompt

In `www/layout.js`, make `cleanName` also remove U+0080-U+009F. Acceptance: `npm test` passes, including
`tests_js/qa-regressions.test.js`; a name pasted with an embedded U+0085 saves without an error.
