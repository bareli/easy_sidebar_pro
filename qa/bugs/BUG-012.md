## Summary

A new group is empty and shows "גררו לכאן פריטים" / "Drop items here". Dragging a panel onto that text
shows no indicator, and releasing there never puts the panel in the group. The drop lands on whatever row
was highlighted last on the way: once the panel landed at the top level after the group, once the drop
merged it with סקירה כללית into a brand-new group. The placeholder invites exactly the action that does
not work.

## Steps to reproduce

1. qa_admin, desktop, open the editor, click Add group, press Enter (an empty group with the placeholder).
2. Drag ימים טובים (`p:good-days`) up onto the placeholder text and release.

## Expected

The panel joins the empty group: the placeholder text says so, and SPEC §3.2 says empty groups exist in
the editor. Workaround today: drop on the group header.

## Actual

No indicator over the placeholder. Run 1 (`p:dash-cameras`): the panel landed at the top level after the
empty group. Run 2 (`p:good-days`): a new group `m8hlsk8c` was created holding `p:home` and
`p:good-days`; the empty group stayed empty.

## Likely root cause

`.empty` is not a `.row[data-key]`, so `_updateTarget` finds no row under the pointer and returns without
a mark and without clearing `d.target` (the stale-target cause in BUG-011). The previous target (a merge
with `p:home` in run 2) is executed on release. The placeholder was never wired as a drop zone. Fixing
BUG-011 alone turns this drop into a no-op; it still does not fill the group.

## Relevant files

- `custom_components/easy_sidebar_pro/www/easy-sidebar-pro.js`: `groupBlock` (`.empty`), `_updateTarget`.

## Recommended remediation

Make the placeholder (or the whole `.children` box of an empty group) a target that resolves to
`{ key: "g:<id>", zone: "into" }` with the `drop-into` mark, plus the BUG-011 reset so no stale target is
ever executed.

## Fix prompt

In `www/easy-sidebar-pro.js`, when the pointer is over an empty group's `.empty` placeholder, set the drag
target to that group with zone `into` and mark the group `drop-into`. Acceptance: dropping a panel on the
placeholder of an empty group makes it that group's only member; no other group is created; dragging a
group onto the placeholder never nests (it lands before / after that group).
