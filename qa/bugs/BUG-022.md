## Summary

SPEC 9.1 says typed input is normalised (`example.com` -> `https://example.com`). It works for a bare
domain (`nas.local` -> `https://nas.local`) and for an IP with a port (`192.168.1.251:5000` ->
`https://192.168.1.251:5000`), but a **host name with a port** is refused with "יש להזין נתיב שמתחיל ב-/ או
כתובת אינטרנט...": `nas.local:5000`, `homeassistant.local:8123`, `my-nas.lan:5000`. These are the
addresses HA users most often link (Synology DSM, another HA, Frigate). Related: UX-013 (the https
rewrite itself, and `nas` -> `/nas`), which does not cover this refusal.

## Steps to reproduce

1. Pencil -> ⋮ on a link -> Address `nas.local:5000`, Enter.
2. Compare `nas.local` and `192.168.1.251:5000`.

## Expected

Same treatment as the domain and the IP:port (SPEC 9.1 normalisation). Whether the scheme should be
https or http is UX-013's question.

## Actual

`nas.local:5000` -> ERR, `homeassistant.local:8123` -> ERR, `192.168.1.251:5000` -> `https://192.168.1.251:5000`,
`nas.local` -> `https://nas.local`. Node: `normalizeUrl("homeassistant.local:8123/x")` -> `null`,
`normalizeUrl("my-nas.lan:5000")` -> `null`, `normalizeUrl("localhost:8123")` -> `null`.

## Evidence

eng-b3.mjs / eng-v3.mjs output above (twice, editor and node).

## Screenshots

![nas.local:5000 refused in the address field](https://github.com/bareli/easy_sidebar_pro/blob/main/qa/evidence/BUG-022-host-port-refused.png?raw=1)

## Likely root cause

`normalizeUrl` (layout.js) first tests `/^[a-z][a-z0-9+.-]*:/i` to detect a scheme; `nas.local:` matches
(dots are legal in a scheme), so the text is treated as an unknown scheme and never gets the `https://`
prefix. IP addresses escape because they start with a digit.

## Relevant files

- `custom_components/easy_sidebar_pro/www/layout.js` (`normalizeUrl`)

## Recommended remediation

Treat `host:digits` (optionally followed by `/`, `?`, `#`) as host and port before the scheme test, e.g.
test `/^[^/\s:]+:\d+(?:[/?#]|$)/` first. Add node cases for `nas.local:5000`, `homeassistant.local:8123/x`,
`localhost:8123`.
