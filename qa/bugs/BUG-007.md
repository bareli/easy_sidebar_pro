## Summary

Standard: WCAG 2.1 SC 1.4.11 Non-text Contrast (AA). The group name is an editable text input styled
`border: 1px solid transparent` (a border appears only on hover and focus), on a grey header row. At rest it
reads as a label, so a sighted or magnifier user cannot tell it is editable. Computed border at rest:
`rgba(0, 0, 0, 0)`. The icon-name field in the same editor has a visible border. Low severity: the focus ring
exists and the editor context suggests editing, but the criterion asks that an input's boundary be identifiable at 3:1 when needed to find it.

## Steps to reproduce

1. Open the editor, add a group "בית".
2. Look at the header row without hovering or focusing the name.

## Expected

A visible 3:1 boundary or equivalent affordance (underline, filled field, edit glyph).

## Actual

No boundary: "בית" is plain text between the folder icon and the ungroup icon.

## Evidence

`name input border: rgba(0, 0, 0, 0)` (computed).

## Likely root cause

Likely: intentional minimal styling, `.name-input { border: 1px solid transparent }` with `:hover` only.

## Relevant files

`custom_components/easy_sidebar_pro/www/easy-sidebar-pro.js`: `EDITOR_CSS` `.name-input`.

## Recommended remediation

A resting border or underline at 3:1 against the header background. Verify in light and dark.
