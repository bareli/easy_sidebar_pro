## Summary

When a user collapses the sidebar to icons with HA's hamburger, the group header keeps its
expanded-mode state. It gets no `icon-only` attribute, so it has no tooltip (`title` = "") and no
folded marker (the inline-start bar). It looks exactly like a panel icon. A page reload, or anything
else that re-renders the sidebar, fixes it. SPEC §3.3 says "tooltip name when the sidebar is
icon-only".

## Steps to reproduce

1. Desktop 1440x900, `qa_admin`, a saved layout with one group; fold the group.
2. Click HA's hamburger in the sidebar header to collapse the sidebar to icons.
3. Hover the group's icon. Inspect `esp-group`.
4. Reload the page and repeat step 3.

## Expected

Step 3 equals step 4: `icon-only` set, `title` = group name, folded marker visible.

## Actual

- Step 3: `title="" iconOnly=false collapsed=true`
- Step 4: `title="בית ומצלמות" iconOnly=true collapsed=true`

## Screenshots

![Right after the toggle (no marker) vs after a reload (marker)](https://github.com/bareli/easy_sidebar_pro/blob/main/qa/evidence/BUG-002-icon-only-stale-vs-reload.png?raw=1)

Note that even after the reload, the folded marker is a faint 3px divider-colour bar that is hard to
see (see the UX note below).

## Likely root cause

Likely: `Controller.render()` computes `iconOnly` from `this.sb.hasAttribute("expanded")` during
`_renderPanels`. Lit reflects the `expanded` attribute after that render, so the value is from the
previous state. Using the reactive property (`this.sb.expanded` / `alwaysExpand`) or refreshing in
`updated()` when `expanded` changed would prove and fix it.

## Relevant files

- `custom_components/easy_sidebar_pro/www/easy-sidebar-pro.js` - `Controller.render()`, `EspGroup.update()`

## Recommended remediation

Derive icon-only from the property, not the reflected attribute. Separately (UX, owner call): in the
icon rail an open group's children are not indented or bracketed, and the folded marker is very
faint, so groups are hard to recognise as groups. A stronger rail treatment (a small chevron badge
on the group icon, children with a thin connecting bar) would help.
