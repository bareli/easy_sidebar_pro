## Summary

HARDENING, reproduced at the API; rendering effect reasoned (not screenshot-verified, see Evidence).
`_name` rejects only Unicode category `Cc`. Category `Cf` (format) characters pass: U+202E (right-to-left
override), U+202C, U+200B (zero width space). A name consisting only of zero-width spaces survives
`strip()` and is accepted, giving a group header with a visible chevron and an invisible name. An admin
default (or a household member's own layout) can therefore show a spoofed or blank name. Real impact is
cosmetic or confusion inside one household, hence LOW. Not an injection: names are only rendered with
`textContent` / `aria-label` / `title` / `<input>.value`.

## Steps to reproduce

Websocket `easy_sidebar_pro/save` as `qa_user`:
1. name `"\u202eevil\u202c"` -> `success: true`
2. name `"\u200b\u200b"` -> `success: true`
(`"\u00a0"` is correctly refused because `strip()` removes it.)

## Expected

Names must be visible text: reject (or strip) bidi controls (U+202A-202E, U+2066-2069) and
zero-width characters, and require at least one visible character after cleaning. This is an inference
from the product's intent (readable group names, Hebrew/English RTL content), not a written rule.
Legitimate Hebrew/English names must keep working (note: U+200F / U+200E marks are sometimes used
deliberately in Hebrew text; decide whether to allow those two).

## Actual

Accepted and persisted.

## Evidence

`qa-sec/t2.py`: `RLO name: ok=True`, `ZWSP-only name: ok=True`, `nbsp-only name: ok=False`.

## Likely root cause

`_name` checks `unicodedata.category(c) == "Cc"` only; `cleanName` in `layout.js` strips only `\u0000-\u001f\u007f`.

## Relevant files

`custom_components/easy_sidebar_pro/layout.py` `_name`; `www/layout.js` `cleanName`.

## Recommended remediation

Reject categories `Cf` (except an explicit allow-list if wanted) and `Zs`/`Zl`/`Zp`-only names; apply the
same rule in `cleanName` so the editor and server agree. Add a Hebrew-name regression case.

## Regression test

`tests/test_layout.py` and `tests_js/` : bidi-override and ZWSP-only names refused; Hebrew names accepted.
