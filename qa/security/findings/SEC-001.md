## Summary

HARDENING, reproduced. `GROUP_ID`, `PANEL` and `ICON` in `layout.py` are matched with `re.match(...)` and
a trailing `$`. In Python `$` also matches just before a final `\n`, so `"abc\n"`, `"map\n"` and
`"mdi:home\n"` are accepted and stored. The browser-side `ICON_RE` (JS) does not accept a trailing
newline, so server and client disagree about what a valid value is. The documented intent
(SPEC / PROJECT.md: "server-side validation is authoritative") is a strict allow-list. No exploit path
found: every render sink uses `textContent`, properties or `CSS.escape` (see SEC-002 notes), so this is
defence in depth, not a reachable defect.

## Steps to reproduce

As `qa_user` (non-admin), websocket `easy_sidebar_pro/save`:

1. `{"version":1,"order":["map\n"],"groups":{}}` -> `success: true`
2. `{"version":1,"order":["g:abc\n"],"groups":{"abc\n":{"name":"n"}}}` -> `success: true`
3. `{"version":1,"order":["g:abc"],"groups":{"abc":{"name":"n","icon":"mdi:home\n"}}}` -> `success: true`
4. Same with `"collapsed": ["abc\n"]` (same regex) is accepted.

## Expected

Each of the above refused with `invalid_format` (as `"MDI:home"` and `"javascript:alert(1)"` are).

## Actual

Accepted and persisted (and, for a default set by an admin, delivered to every user).

## Evidence

Session `qa-sec/t2.py` (scratchpad), user `qa_user`, nothing secret in the exchange:
`panel newline: ok=True`, `gid newline: ok=True`, `icon newline: ok=True`; by contrast
`icon uppercase: ok=False "invalid icon"`, `html icon: ok=False "invalid icon"`.

## Likely root cause

`re.match(r"^...$")` instead of `re.fullmatch(r"...")` in `GROUP_ID`, `PANEL`, `ICON` usage
(`_panel`, group loop, icon check, `validate_collapsed`).

## Relevant files

`custom_components/easy_sidebar_pro/layout.py` lines 10-12, 31, 75, 82, 108.

## Recommended remediation

Use `fullmatch` (or `\Z`) for all three patterns and `validate_collapsed`. Add a test per field with a
trailing `\n`. Also reject `version is True` (`True == 1` passes the version check today;
`isinstance(v, bool)` guard).

## Regression test

`tests/test_layout.py`: parametrised trailing-newline cases for panel, group id, icon, collapsed.

## Note from the functional review

The icon pattern also accepts values such as `javascript:alert` (it matches `prefix:name`). It is inert today (only ever set as the `ha-icon` `icon` property), but the fix should restrict the prefix to known icon sets (`mdi`, `hass`, ...) or at least to what HA's icon loader accepts.
