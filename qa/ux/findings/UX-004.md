## Problem

Three footer links, styled identically as plain blue text links, each act on one tap:

| Link (he / en) | What it does | Feedback |
|---|---|---|
| חזרה לפריסת ברירת המחדל / Reset to the default layout | **Deletes the user's own layout** (groups, names, icons). No undo. | Editor closes. |
| קביעה כברירת מחדל לכולם / Set as default for everyone | Saves the admin's layout, then **changes every un-customised user's sidebar live**. | Editor closes; looks identical to Done. |
| ביטול פריסת ברירת המחדל / Remove the default layout | Removes the default for everyone. | Nothing visible; the editor stays open. |

On a phone the links sit right under the last panel row, where a fling-scroll and tap can land.

"Ungroup with no confirmation" is fine (in-editor, Cancel undoes it). These three are different:
they commit immediately and Cancel does not undo them.

## Why it matters

Reset destroys work a person spent minutes on, with no undo. The two admin actions change other
people's screens, and the admin gets no sign that it worked ("did it publish, or did I just press
Done?"). Remove-default gives no feedback at all.

## Evidence

![Footer link, then the editor simply closes after Set as default](https://github.com/bareli/easy_sidebar_pro/blob/main/qa/evidence/UX-004-set-default-no-confirm.png?raw=1)

Left: the admin footer with "קביעה כברירת מחדל לכולם". Right: one tap later the editor is closed
with no message; `subscribe` confirms `hasDefault:true`. For Reset, `qa_user` went from `own:true`
to `own:false` in one tap (see UX-001 evidence, right panel).

## Recommendation

- Reset: a confirm with the consequence in plain words: "למחוק את הסידור שלך ולחזור לסידור של
  הבית?" / "Delete your sidebar layout and go back to the household default?" [Delete] [Keep]. Or,
  better, make it an editor action that Cancel can undo (it only shows the default in the editor;
  Done commits it).
- Set as default: a confirm that names the reach: "This replaces the sidebar of every user who has
  not customised theirs (N users)." Then a short toast: "Default published."
- Remove default: confirm, then a toast. Also refresh the footer and the note so the state change
  is visible.
- Visually separate the admin section ("For everyone" subheading) from the personal Reset link.

Copy is the owner's call.
