## Summary

Any well-formed id is accepted, even one that does not exist. For show-only-when an unknown entity is never active, so the whole group (and every panel in it) vanishes from the sidebar with no sign of why. For a badge nothing ever shows. A family member who typed `input_boolean.alrm` sees a sidebar that lost its panels.

## Steps to reproduce

1. Editor, group More, Show only while: type `counter.nonexistent` or `input_boolean.alrm`, Enter: no message.
2. Saved layout with `items.g:b.show_when = input_boolean.alrm` (group holding History): after Done the sidebar renders 0 groups and History is gone (measured).

## Expected

On commit an id that is not in `hass.states` gets a visible, non-blocking warning ("No entity with this id"); same for badge.

## Actual

No message; measured 0 `esp-group` rendered.
