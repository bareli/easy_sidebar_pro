## Summary

At 320x568 the pinned editor header (title, Done / Cancel, three-line hint, Display options) takes about 195 px; HA's Settings / Notifications / profile take about 150 px at the bottom. With a link's block open about 110 CSS px scroll: two fields visible, less with the keyboard. A link block has nine controls. Tap targets: ⋮ 36x36, eye 36x36, drag handle 32x36 (below the usual 44 px for a wall tablet or a phone).

## Steps to reproduce

Phone 320x568, open the drawer, edit, Add link, tap Address.

## Expected

Header collapses after the first scroll or the hint is dismissible; link block shows name + address first and the rest under a fold; 44 px targets.

## Actual

Measured sizes as above.
