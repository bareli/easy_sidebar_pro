## Summary

The datalist options carry only the id (label and text empty). A family member knows "חלונות פתוחים" or "אזעקה", not `counter.open_windows`. Typing a Hebrew name matches nothing and then shows the format error. On a real install (hundreds of entities) it is a wall of ids; datalist behaviour on phones and in the companion app is browser dependent.

## Steps to reproduce

1. Editor, More, Badge entity: type `חלונות` or `Alarm`: no suggestion, then "יש להזין מזהה ישות...".
2. Inspect `#esp-entities`: 18 options, only `value` set.

## Expected

Suggestions show friendly name plus id and match on both, or a small entity picker.

## Actual

Ids only (measured: `conversation.home_assistant`, `counter.open_windows`, ... label empty).
